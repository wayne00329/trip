# 家庭共編版

這個版本由 Node.js 伺服器提供登入、行程編輯和 SQLite 資料庫。用同一組帳密登入的家人，共用網站上的所有旅程。

## 在 Windows 本機試用

在檔案總管雙擊 `start-family.cmd`，或從 `C:\trip` 開啟 PowerShell，使用 Node.js 24 執行以下指令。

```powershell
node family/server.mjs
```

開啟 `http://127.0.0.1:4173`。首次使用時，直接在網頁設定家庭帳號和至少 12 個字元的密碼，再登入。要測試兩個家庭成員，分別用一般視窗及無痕視窗登入。行程儲存後，其他正在瀏覽的裝置約五秒內會看到更新。若兩人同時開啟表單，先儲存的版本會留在伺服器，較晚送出的修改可先下載備份，再載入共用版本並重做該次變更。

## 讓其他地方的家人使用

將 `family` 資料夾部署到能執行 Node.js 24 且有持久磁碟的主機。透過 HTTPS 反向代理指向 Node.js 服務，將 `TRIP_PUBLIC_ORIGIN` 設為對外的完整網站來源（例如 `https://trip.example.com`），並將 `TRIP_DATA_DIR` 設為持久磁碟上的資料夾。Node.js 預設監聽 `127.0.0.1:4173`。需要從容器網路或其他介面存取時，用 `TRIP_HOST` 和 `PORT` 調整監聽位置。網站需部署在網址的根路徑。

在該主機使用相同的資料目錄執行 `node server.mjs setup`，再以 `node server.mjs` 啟動服務。無互動的部署環境可由主機的秘密設定提供 `TRIP_USERNAME` 和 `TRIP_PASSWORD`，只在執行 `setup` 時使用。把 HTTPS 網址和家庭帳密私下提供給家人。重新執行 `setup` 可更換帳密並登出既有工作階段，行程資料會保留。

GitHub Pages 只提供靜態檔案，家庭登入與共用儲存需要上述伺服器。舊版的瀏覽器資料可逐趟匯出，登入家庭版後用「匯入」載入為新共用旅程。伺服器的預設資料目錄是 `family/.data/`，備份時可用網頁的匯出功能，或在服務停止後備份整個資料目錄。
